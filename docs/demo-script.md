# Demo Script (75-90 seconds)

1. **Introduction:** "This is JALREKHA, a planning simulation for disaster response with assumed population and shelter capacity along the Pune river corridor."
2. **Baseline:** Start at the 0.0m scenario. Show the baseline allocation of populations from assembly points to candidate shelters.
3. **Scenario Change:** Increase the scenario level to 1.5m. Show the visual water overlay and the modeled accessibility changes as some roads become unavailable.
4. **Intervention:** Apply one real graph-edge closure to represent a manually closed road. Point out how a population group gets rerouted or becomes unreachable.
5. **Capacity Adjustment:** Show the constrained plan struggling, then manually "open" the additional candidate shelter to see the system instantly reallocate people to it.
6. **Comparison:** Explain the "Allocated vs Unallocated" change and point out the optimized allocation logic vs the baseline.
7. **Export:** Click the Export button (if implemented in UI) or demonstrate the JSON payload explaining the routes.
8. **Conclusion:** "This demonstrates our method for dynamic resource allocation. The next validation step involves integrating real-time weather APIs and traffic models."
